# Real-Time E-Commerce Order Pipeline

## Project Overview

Real-time data engineering pipeline using Kafka, PySpark Structured Streaming and MySQL.


## Technologes Used

- Python
- Apache Kafka
- PySpark
- Structured Streaming
- MySQL
- Docker

## Architecture


CSV Dataset

↓

Kafka Producer

↓

Kafka Topic

↓

PySpark Streaming

↓

Data Transformation

↓

MySQL


## Features

- Real-time order processing
- JSON message parsing
- Data cleaning
- Business transformations
- Streaming analytics
- MySQL storage
- Error handling
- Checkpointrecovery
- Performance otimization
